WoSB Workbench v3.10.0 — Buildable complete source

1. Open this folder in Windows.
2. Double-click Build-Windows.cmd (Python 3.13 installed).
3. Launch dist\WoSBWorkbench\WoSBWorkbench.exe or use the built updater ZIP.
4. Open Full Recovery, browse to the installed WoSB game, click Recover Everything.
5. In Ship 3D, choose the game Data directory OR your WOSB-Upload-Parts
   directory containing WOSB-Research-Part-001.zip through Part-036.zip.
6. Load/recover a ship OBJ and open its visualizer, switch actual designs,
   or choose Export textured GLB for an independently viewable 3D model.
7. Inspect the recovery coverage reports. Results include unsupported
   reader types and unverified damage formulas; these are NOT hidden.

This is source code. The Windows executable is generated by Build-Windows.cmd.
Existing personal wiki and imported data are stored in %LOCALAPPDATA%\WoSBWorkbench.
Back up that folder before intentionally uninstalling with user-data cleanup.

See RELEASE-NOTES-v3.10.md for capabilities, evidence, known limits,
full validation results, and proper updater ZIP selection.
