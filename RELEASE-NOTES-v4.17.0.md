# WoSB Workbench 4.17.0

- **Trade goods** (new guide page): which trade goods each sea economy (North, South, Arab, Center) sells, which goods are only found on islands, what every port stocks (with typical lot sizes) and what every port pays for each good, with the best place to sell each one highlighted. Worked out from the game's own trading rules and its map of sea regions.
- **Port pages** now have a Trade goods section: the port's sea region and danger level, the regional goods on offer, the basic goods always on sale, and the goods that sell best there.
- **Dig sites, ruins and buried treasure** (new guide page): how often each turns up, what each holds, and a table of what a dig site gives in each of the 16 sea regions, including which island trade good you can dig up there.
- The sea-region map is now bundled with the Workbench, so these pages build without a fresh Full Recovery.
