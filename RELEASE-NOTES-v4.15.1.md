# WoSB Workbench 4.15.1

- **Imperial forts are not all the same**: the game has three fort buildings. Type 1 (27 guns, 26 forts on the map), type 2 (27 guns laid out differently, 2 forts) and type 3 (30 guns, not placed on the open-sea map yet). The forts page now shows each type from above with its own gun coverage, safest directions and where it stands; the world map names each fort's type and links to its safest angles.
- New `scripts/fort_coverage.py` rebuilds the fort data and pictures from the game's fort models.
